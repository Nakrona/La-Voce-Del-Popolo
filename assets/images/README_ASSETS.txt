LA VOCE DEL POPOLO - PANDUAN REPLACE ASSETS GAMBAR (PNG / GIF / WEBP / JPG)
================================================================================
Semua gambar game dikelola melalui folder `assets/images/` dan `js/config/AssetConfig.js`.

CARA MENGGANTI ASSET KAPAN SAJA:
1. Timpa file gambar di bawah ini dengan nama file yang sama (mis. ganti `units/mahasiswa.png`
   dengan gambar Mahasiswa versi Anda sendiri).
2. SUPPORT ANIMASI GIF:
   - Anda bisa langsung menghapus file `.png` (misal hapus `units/mahasiswa.png`) lalu menaruh
     `units/mahasiswa.gif` di folder yang sama, ATAU ubah ekstensi di `js/config/AssetConfig.js`.
   - Sistem akan otomatis mendeteksi `.gif` dan memutar animasi GIF-nya secara penuh di browser!
